**#Karel-my first robot**

**What is Karel?**

Karel is my work from the first four weeks of COSC 10001 (The Computer Science Experience) at TCU. Karel is a robot that only knows four commands:

move();          // walk forward one square

turnLeft();      // rotate 90 degrees to the left

pickBeeper();    // pick up a beeper from the square you are standing on

putBeeper();     // put a beeper down on the square you are standing on

**How do you run Karel?**

Open the folder in IntelliJ and press the green "play" button, or run.ps1 on Windows and run.sh on macOS.

**What I learned while working on Karel:**

Karel has no turnRight(), so to build a right turn I used three turnLeft().
